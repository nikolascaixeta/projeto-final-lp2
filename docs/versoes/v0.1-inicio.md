# Estado do projeto no início

Home -> Essa página mostra os conteúdos presentes no site, fala sobre os criadores do site e sobre a instituição F1 Wiki.

Equipes -> Essa página mostra cards com as 11 equipes presentes na temporada atual da F1 com o carro principal, logo e corredores, cada card leva para uma outra página com conteúdos mais aprofundados sobre a equipe.

Pilotos -> Essa página mostra os 22 pilotos, com um filtro, ao clicar em cada card de piloto aparece conteúdos relacionados ao piloto.

Historia -> Essa página fala sobre a história da F1

Troféus -> Essa página fala sobre os troféus de cada Gp da temporada 2026, cada um leva para uma página com conteúdos mais aprofundados

Lendas -> Essa página fala sobre as lendas que já passaram na F1.
